# Striver's A2Z DSA Course Solutions 🚀

This repository contains my solutions to problems from [Striver's A2Z DSA Course](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2). I'm following this comprehensive course to strengthen my problem-solving skills and master Data Structures & Algorithms.

## 📚 About the Course

Striver's A2Z DSA Course is a structured learning path designed to take you from basics to advanced DSA concepts. The course covers:

- Pattern Problems
- Basic Mathematics
- Recursion
- Hashing
- Important Sorting Techniques
- Array Problems (Level-1, Level-2, Level-3)
- And much more...

**Course Link:** [Striver's A2Z DSA Course Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2)
